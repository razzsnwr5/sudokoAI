# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Common Commands
- Develop: `npm start`
- Build: `npm run build`
- Test: `npm test`
- Run single test: `npm test -- <pattern>`

## Architecture
This is a standard React application created with Create React App (CRA).

- `src/`: Contains the application source code.
  - `App.js`: The main root component.
  - `index.js`: The application entry point.
- `public/`: Contains static assets and the `index.html` template.
- `package.json`: Defines dependencies and scripts.
